张娜
张娜
小米-招聘经理
Job description
:
Support the operation, maintenance, and development of the company's overseas data warehouse (mobile device, IoT, and app data domains)
Develop and implement data processing techniques and analytics applications to transform raw data into meaningful insights
Build and maintain ETL/ELT pipelines using data-oriented programming languages (e.g., Python, SQL)
Apply basic data modeling and data mining techniques to process structured and semi-structured datasets
Assist in analyzing large datasets and generating insights to support overseas business operations
Create data visualizations and simple reports using BI or visualization tools (e.g., Tableau, Power BI, or similar)
Collaborate with cross-functional teams to understand data requirements and support analytics use cases
Participate in testing, deployment, and monitoring of data workflows
Requirement
:
Bachelor’s degree in Computer Science, Software Engineering, Data Science, or a related field
1–3 years of experience in data engineering, data analytics, or a related role
Familiarity with big data frameworks such as Hadoop, Spark, or Flink
Proficiency in SQL and at least one programming language (Python, Java, or Scala)
Basic understanding of data modeling and data warehousing concepts
Exposure to data visualization tools (e.g., Tableau, Power BI)
Basic knowledge of data mining or machine learning concepts is a plus
Good communication and teamwork skills.Ability to communicate in Mandarin and English, in order to support coordination and collaboration with Mandarin-speaking stakeholders, teams, and business partners across regional markets.
