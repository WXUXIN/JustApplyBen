Optimum Solutions Pte Ltd provided pay range
This range is provided by Optimum Solutions Pte Ltd. Your actual pay will be based on your skills and experience — talk with your recruiter to learn more.
Base pay range
SGD 7,000.00/mo - SGD 8,000.00/mo
Our client, a leading financial regulatory institution, is looking for a
Data Engineer
to develop and maintain data pipelines, integrate data sources, and build scalable data solutions to support its data-driven initiatives.
Key Responsibilities
Design, develop and maintain data tables, data marts, and data warehouse solutions.
Build and maintain ETL/ELT pipelines for data extraction, cleaning, transformation and integration.
Develop batch and real-time data pipelines to support large-scale data processing.
Integrate data from multiple sources while ensuring data quality, scalability and compliance.
Develop backend APIs and work with databases to support applications.
Collaborate with data architects, analysts, developers and project teams to deliver data-driven solutions.
Participate in Agile development, CI/CD, code reviews and pair programming.
Requirements
2–4 years of experience in Data Engineering or a related field.
Proficient in SQL and Python for data processing, cleaning and transformation.
Hands-on experience developing ETL/ELT pipelines using tools such as AWS Glue, Lambda, DMS, SSIS or equivalent.
Experience with relational and NoSQL databases such as PostgreSQL, MySQL, MongoDB or SQL Server.
Familiarity with cloud platforms such as AWS, Azure or Google Cloud.
Understanding of data modelling, data warehousing, data lakes and database design.
Knowledge of REST APIs, data integration and web requests.
Familiarity with big data technologies such as Spark, Hadoop or Kafka.
Understanding of data governance, access control and security best practices.
Comfortable working in Windows and Linux environments.
Good to Have
Experience with Apache Airflow and RDBMS integration.
Exposure to Snowflake, Databricks or similar data platforms.
Experience integrating data pipelines with search indexes.
Exposure to web scraping tools such as BeautifulSoup or Selenium.
